{# hero-label.html Reusable macro for a single moving orbit annotation: a small dot that sits exactly on the orbit path, plus a floating text label offset beside it. The four hero labels are all produced from this one macro instead of four hand-written copies of the same markup. orbit: "a" or "b", identifies which ellipse the label travels along. phase: starting angle in degrees along that ellipse. The two labels on the same orbit must be 180 degrees apart so they never collide. The text's side (right/left/top/bottom) is set and kept in sync by orbit-animation.js via the [data-side] attribute, not by this markup. #} {% macro hero_label(text, orbit, phase) %}
