{# safety-orbit.html Reusable "safety orbital" visualization: a stable central shield surrounded by concentric protection rings, a slow-rotating ring of safety words, a scanning arc, and a handful of connected safety nodes. See safety-orbit.css for appearance and safety-orbit-geometry.js / safety-orbit-animation.js for the single requestAnimationFrame loop that drives every moving part. Purely decorative (aria-hidden): the words and shield don't carry information that isn't already in the surrounding page copy, the same reasoning the About hero's own headline/description already cover the page's meaning without this needing its own accessible text. Configurable via macro arguments, without touching this file or the CSS/JS: shield_icon - name from macros/icons.html (default "safety") words - list of 5-8 short uppercase safety-related words center_label - optional short label under the shield (default: none) size - a named size variant ("default" or "compact"), not an arbitrary CSS length: applied as a modifier class (safety-orbit.css defines each variant's --safety-orbit-size), deliberately not as an inline style. The site's CSP has no style-src exception for inline styles, and just as importantly, an inline-set custom property would always outrank the component's own phone-width media query (inline beats any stylesheet rule regardless of specificity), permanently defeating the mobile simplification for any caller that set a custom size.
