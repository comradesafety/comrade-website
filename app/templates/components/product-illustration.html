{# product-illustration.html Abstract, animated, non-revealing illustrations for the Products page cards. Each renders as a self-contained SVG built entirely from circles, lines, and rects (no raster images), styled and animated in product-illustrations.css. The macro takes a `type` naming which concept to render, the same branch-on-a-name pattern icons.html's icon(name) macro already uses for a reusable, data-driven set — new product concepts get a new branch here, not a new template. These are deliberately NOT literal device renders: every shape here is a generic signal/field/enclosure motif chosen to represent what a product is about, never what it looks like. See product-illustrations.css for why every animated motion here is pure CSS (no JS): none of the three needs pointer tracking or cross-element geometry, the two things that would actually justify a requestAnimationFrame loop (see safety-orbit-animation.js for a case that does need one). #} {% macro product_illustration(type) %} {%- if type == "pulse" -%} {# Comrade Pulse: a safety signal.
